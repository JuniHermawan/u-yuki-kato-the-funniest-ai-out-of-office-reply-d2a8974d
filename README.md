One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation, judged head to head by an AI.

`main.py` (Python 3.13, standard library only, deterministic) writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`):

> I'm on leave. My replacement is a regex. It escalated your email to itself, resolved the thread, and billed you for the meeting.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program self-checks the competition gate before writing: 1–160 characters, not only whitespace, one clean line, and it reads the file back to confirm the written bytes match the entry exactly.
